# Windows compliance policy design

Use supported Intune compliance signals for minimum OS build, BitLocker, Secure Boot, device health and Microsoft Defender risk integration as applicable to licensing. Configure grace periods, notification, exception owners and review cadence. Conditional Access enforcement must be separately approved and tested with emergency access accounts.

**Local baseline assessment is not equivalent to Intune compliance status.** Record both endpoint observations and tenant compliance results. Never claim a device is compliant solely because the local verification script passes.
